ẢNH SẢN PHẨM
============

Bỏ ảnh vào ĐÚNG thư mục này. Không cần sửa Google Sheet.

CÁCH ĐẶT TÊN FILE
-----------------
Đặt tên file bằng "Hãng + Tên sản phẩm" y như trong Sheet.

  Sheet ghi:  Razer | Viper v3 pro
  Đặt tên:    Razer Viper v3 pro.jpg

Hoặc chỉ cần tên sản phẩm cũng được:

  Viper v3 pro.jpg

KHÔNG cần lo hoa thường, dấu tiếng Việt hay khoảng trắng — hệ thống bỏ qua
hết khi so khớp. Ba tên dưới đây đều khớp cùng một món:

  Razer Viper v3 pro.jpg
  razer-viper-v3-pro.webp
  RAZER VIPER V3 PRO.png

Đuôi file nhận: .jpg .jpeg .png .webp .avif .gif

ẢNH NÊN NHƯ THẾ NÀO
-------------------
- Hình vuông (ví dụ 1000 x 1000 pixel)
- Nền trắng hoặc nền sáng, đơn giản
- Dưới 300KB mỗi ảnh cho trang tải nhanh
- Chụp rõ chỗ trầy xước nếu có — bán đồ cũ thì ảnh thật là lợi thế

CÁCH TẢI LÊN (không cần cài gì)
--------------------------------
1. Mở https://github.com/luuquocviet005/K-o-Gaming-Shop
2. Vào thư mục public > products
3. Bấm "Add file" > "Upload files"
4. Kéo thả ảnh vào, rồi bấm "Commit changes"

Xong. Khoảng 20 phút sau web tự cập nhật, hoặc vào tab Actions bấm
"Đồng bộ Google Sheet" > "Run workflow" để cập nhật ngay.

MUỐN CHỈ ĐỊNH ẢNH CỤ THỂ CHO MỘT MÓN?
--------------------------------------
Ghi tên file vào cột "Ảnh" trong Sheet, ví dụ: chuot-razer-01.jpg
Cột "Ảnh" luôn được ưu tiên hơn việc tự tìm theo tên.

Cột "Ảnh" cũng nhận link ảnh trực tiếp (kết thúc bằng .jpg/.webp)
và link FILE Google Drive dạng .../file/d/<ID>/view
(link THƯ MỤC Drive thì không dùng được vì không trỏ tới ảnh cụ thể nào).
