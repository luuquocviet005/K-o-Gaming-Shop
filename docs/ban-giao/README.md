# Sổ bàn giao giữa các AI

Mỗi lần làm xong (hoặc phải dừng giữa chừng) thì thêm **một file mới** ở đây.
Không sửa, không nối vào file của lượt trước. Luật đầy đủ ở `AGENTS.md`.

Tên file: `YYYY-MM-DD-<ai>-<viec>.md` (ví dụ `2026-10-21-anti-them-chatbox.md`).
AI mới vào chỉ cần đọc 3 file mới nhất.

## Mẫu

```markdown
# <Việc gì> — <claude | anti>, <ngày>

**Nhánh / PR:** <tên nhánh, link PR nếu có>

## Đã làm
- …

## Còn dở / cần chủ shop quyết
- …

## AI sau cần biết
- …
```
